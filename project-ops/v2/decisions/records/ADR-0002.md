# ADR-0002 — Do not multiply P3 experimental milestones

**ID:** ADR-0002
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** delivery governance, P3 checkpoints, six D1–D6 milestones
**Decision:** Treat P3-0..41 as experiments/proofs and organize remaining delivery around fixed D1–D6; stop inventing new pseudo-milestones.
**Alternative considered / why rejected:** Open-ended P3-N numbering obscured readiness and delayed end-user delivery; a finite sequence forces explicit acceptance gates.
**Reconsider only if:** Reconsider only after an owner-approved scope change requires a named milestone with an actual outcome.
**Original evidence / approval:** [Source](https://github.com/ginosega/fishing/blob/406723f880960d33d40bd07984559432c8caa233/experiments/p3/preview/FISH118_V3_Finite_Delivery_Reset_2026-10-25.md#L15-L94)
**Provenance note:** Preserve all technical/security gates inside milestones. Not permission to skip validation.
**Supersedes / superseded by:** None unless the linked original or a later owner-approved amendment specifies otherwise.
