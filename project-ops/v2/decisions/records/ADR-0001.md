# ADR-0001 — Single owner-facing gateway; no extra publication attestor

**ID:** ADR-0001
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** publishing architecture, owner authentication, trust boundary, avoided extra signer
**Decision:** One same-origin owner-facing service with owner OAuth/CSRF, protected PR/CI/merge, and source/host verification; public static Pages release is separately guarded.
**Alternative considered / why rejected:** Separate attestor/per-content signature was explicitly unnecessary; adding another trust layer would increase operating burden without a demonstrated security requirement.
**Reconsider only if:** Reconsider only if a documented threat model, requirement or verified provider constraint makes the chosen single-gateway path insufficient.

**Provenance note:** D1 selected architecture, distinct from authorization to enable any Worker writing or deploy secrets.
