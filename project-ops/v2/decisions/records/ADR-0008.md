# ADR-0008 — Static recovery prompt with active router and searchable decision memory

**ID:** ADR-0008
**Status:** accepted — adopted under P5 after P4 recovery acceptance and independent required CI
**Scope / search tags:** Operating Model v2, emergency recovery, chat context, decision retrieval
**Decision:** Use an invariant copyable recovery prompt on the default branch, small dynamically maintained router and bounded working docs; consult topic-sharded accepted/rejected decision history before material proposals.
**Alternative considered / why rejected:** Five canonical files and giant full bootstrap accumulated repeated status and historically superseded instructions, creating fragility and repeated context load.
**Reconsider only if:** Reconsider workflow after an evaluated cold-start failure or explicit later owner-approved operating-rule amendment.
**Original evidence / approval:** [Source](https://github.com/ginosega/fishing/issues/282)
**Provenance note:** P1 design approved November 1, 2026; P4 field recovery tests passed and P5 project-governance activation completed through default-main router PR #292. Application V3 deployment remains an independent, unapproved decision.
**Supersedes / superseded by:** None unless the linked original or a later owner-approved amendment specifies otherwise.
