# ADR-0009 — Governance validation independent of PWA application release

**ID:** ADR-0009
**Status:** accepted (owner-approved November 1, 2026; governance adoption still pending)
**Scope / search tags:** governance, P3, docs validation, PWA decoupling, FISH108, CI, browser tests, main-based branch
**Problem:** A documentation validator was inserted into the existing PWA release workflow, where non-Markdown tooling changes rightly invoked the full application browser suite. Pre-existing offline-library Playwright timeouts then blocked the separate governance initiative despite the documentation checks passing.
**Decision:** Carry the operating-model Markdown corpus on an independent docs-only branch based directly on `main`, validate governance structure and institutional-memory semantics independently, and leave the PWA release workflow and tests untouched. An independently installable permanent governance CI is tracked as a separate follow-up. Do not claim that the currently separate per-change checks are a permanent required CI status.
**Alternative considered / why rejected:** Repairing V3's offline-library test failures as a prerequisite to governance was rejected as unrelated scope expansion. Waiving or downgrading existing FISH108 tests merely to merge a governance tool was also rejected.
**Reconsider only if:** Owner approves a distinct and independently reviewable governance CI integration that preserves application test requirements, or new evidence shows the documentation itself genuinely depends on runtime behavior.
**Original evidence / approval:** [Owner-approved independent-governance amendment](../../OWNER_AMENDMENT_INDEPENDENT_GOVERNANCE_2026-11-01.md) · [issue #282](https://github.com/ginosega/fishing/issues/282) · [PWA blocker #287](https://github.com/ginosega/fishing/issues/287).
**Supersedes / superseded by:** Supersedes the proposed V3-coupled P3 implementation sequence in [original P1 documentation validation design](../../DOC_VALIDATION_DESIGN.md); **not** FISH108 or any V3 technical/product approval.

An accepted design choice is not proof that governance has reached P5 adoption. The public PWA's deploy state and V3 Worker are independent evidence domains.
