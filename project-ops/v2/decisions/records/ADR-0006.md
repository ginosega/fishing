# ADR-0006 — Historical approvals are pinned, later changes are individually approved

**ID:** ADR-0006
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** approval provenance, V3 October 19 requirements, later amendments
**Decision:** Preserve reviewed Oct 19 requirements/design/UX/plan blobs and their distinct approval records. Index later owner-approved changes by date/scope with supersession relation.
**Alternative considered / why rejected:** Prepending new requirements or field status above a signed original may misleadingly imply later features were already approved on original date.
**Reconsider only if:** Reconsider only via a transparent new version/approval process; never retroactively modify the original approval claim.
**Original evidence / approval:** [Source](https://github.com/ginosega/fishing/blob/406723f880960d33d40bd07984559432c8caa233/pwa/docs/Fishing_Companion_v3_Requirements_Approval_2026-10-19.md)
**Provenance note:** Operating Model v2 P1 approved Nov 1, 2026; adoption awaits docs/CI/cold-start.
**Supersedes / superseded by:** None unless the linked original or a later owner-approved amendment specifies otherwise.
