# ADR-0005 — Catch Notes image scope is not the Catch cover field

**ID:** ADR-0005
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** Catch Notes photographs, cover, Picture Viewer, schema
**Decision:** Inline uploaded image references are allowed inside Catch Notes; representative Catch cover remains derived from Species; Gear/KB and Catch Notes share safe Markdown authoring.
**Alternative considered / why rejected:** Earlier Catch-photo exclusion applied to representative/cover picture and must not be over-broadly read to forbid Notes images.
**Reconsider only if:** Reconsider only with a specifically approved Catch schema/cover behavior change.
