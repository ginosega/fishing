# ADR-0007 — Preserve negative fishing-content lessons and explicitly retired pages

**ID:** ADR-0007
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** KB editorial, retired Techniques, species behavior, evidence standards
**Decision:** Keep editorial separation (Behavior & Habitat where/why; Techniques how; Seasons contextual combination), curated crosslinks and retired generic Technique pages retired.

**Reconsider only if:** Reconsider retired pages only on explicit user request and evidence of distinct editorial value.
