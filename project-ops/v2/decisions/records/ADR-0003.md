# ADR-0003 — No whole-prototype merge into public main

**ID:** ADR-0003
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** GitHub source integration, PR #262/#263, risk of unrelated code
**Decision:** Port only selected reviewed and validated modules into the intended integration branch; do not merge draft prototype branches wholesale as a unit.
**Alternative considered / why rejected:** Prototype branches contain experiments and state that cannot be treated as independently validated production changes.
**Reconsider only if:** Reconsider only through separate reviewed integration PR with full applicable release evidence and owner cutover authorization.
**Original evidence / approval:** [Source](https://github.com/ginosega/fishing/blob/406723f880960d33d40bd07984559432c8caa233/experiments/p3/preview/D1_V3_Architecture_Consolidation_2026-10-25.md#L32-L46)
**Provenance note:** D1 instruction retains explicit caution about unrelated PRs and public V2.
**Supersedes / superseded by:** None unless the linked original or a later owner-approved amendment specifies otherwise.
