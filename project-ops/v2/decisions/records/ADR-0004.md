# ADR-0004 — V3 text publication must reach independently verified Live in 60 seconds

**ID:** ADR-0004
**Status:** accepted (historical decision / P1 proposal where noted; activation gates remain)
**Scope / search tags:** publishing performance V3-SAVE-09 latency evidence
**Decision:** Valid ordinary text-only Gear/KB/Catch source changes complete from Save and Publish to independently verified public hosted Live within 60 seconds in normal operation.
**Alternative considered / why rejected:** Prior FISH108 few-minute target was insufficient for accepted V3 end-user experience. A queue, PR merge or accepted HTTP response cannot stop the timer.
**Reconsider only if:** Reconsider only after explicit user-approved requirement amendment; evidenced external provider outages are the sole established exception.
