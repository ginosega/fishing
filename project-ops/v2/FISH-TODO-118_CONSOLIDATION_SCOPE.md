## Final single-authority contract

- **Online records / Markdown:** one D1 content graph for Gear, KB, Catches. No permanent immutable JSON overlay or frozen-count cap. Independently reconcile the baseline 100 Gear / 60 KB / 12 Catches without re-importing or overwriting owner edits.
- **Content images:** one private R2 bucket for all historical V1/V2 + new V3 photos, cover photos, Notes images and KB Knot sequences; D1 holds verified references and ownership; logical paths remain stable. Old source and immutable copies remain *backup/archive* until acceptance, never a second live authority. Static UI icons/JS/CSS remain in software releases.
- **Writes:** one owner-authenticated, CSRF-protected, expected-revision transactional D1 Create/Edit/Save contract with optional atomically published media references, no GitHub per-edit publication or offline sync queue.
- **Offline:** explicit user-triggered verified *current content* snapshot, independently versioned from immutable software, coherent D1 records + Markdown + referenced R2 assets, installed-PWA-compatible. Work Offline stays strictly read-only, no network reads, no partial snapshot selection and no automatic full download merely for app launch. Drafts preserved and no automatic cross-revision overwrite.
- **Safeguards:** original hashes + sizes, schema/link validation, last-known-good complete snapshot, independent software-content compatibility, cache eviction/quota handling, owner Edge + Android field acceptance. Preserve REL-007 deferral for inline Notes derivatives (card thumbnails are in scope).
