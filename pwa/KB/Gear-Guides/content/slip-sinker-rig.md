# Rigging
`Main line → 1/2 oz. egg sinker → bead → swivel → leader → #4 hook`

# Weight
Use 1/2 oz. generally, 1/4 oz. for lighter line & smaller fish.

# Bait
Run a worm up the hook to the eye, or use PowerBait dough, nugget, or egg
