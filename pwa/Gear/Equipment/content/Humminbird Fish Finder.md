## Controls
- Power: 
  - Press to turn on, long-press to turn off
  - While on, press to use Sonar, Backlight, Background, and Standby menus
- \+ \/ \- "zoom" keys
  - While in sonar zoom view, adjusts zoom range
  - While in sonar views, adjusts sensitivity
  - While in chart views, adjusts chart range
- VIEW: 
  - Press to rotate views (rotate backwards using Exit), long-press to open View X-Press menu
- Cursor pad:
  - Moves active cursor in sonar and chart views
  - Navigates menus
- MENU:
  - Press once to open an X-Press menu
  - Press twice to open the main menu
- Check ("P"):
  - While in chart view, opens chart info submenu
  - While in sonar views, switches frequencies
  - When cursor is active in chart view, displays chart info
- MARK:
  - Press once to mark a waypoint at the boat's position
  - Press twice to mark a waypoint at the cursor position
  - Press and hold to save a screenshot if SD card is installed
- GOTO/MOB:
  - Press once to display saved navigation data
  - When cursor is active, press once to start navigation towards a waypoint
- EXIT:
  - Close a menu, exit active cursor, or turn off an alarm
  - Press to rotate view backwards (rotate forwards using View)

## Setup
- Quick Setup menu: 
  - Should launch on first use; if not see Set Up Sonar, p. 39
  - Max Depth: Lake Sammamish 105'; Lake Washington 214'
  - Water Type: Fresh
- Verify GPS reception:
  - Press & hold VIEW: System > GPS Diagnostic View
  - Fix Type: Should be Enhanced (best) or 3D
  - Lat/Lon should be displayed; confirm with Navionics app
- Test the transducer:
    1. Put boat in ≥ 2' water
    2. Turn on control head
    3. Press & hold VIEW: Sonar > Sonar View
    4. Verify that bottom is visible and depth is shown
    5. Paddle full speed and verify that bottom is not skipped or missed
- Set up sonar (p. 60):
  - Press MENU twice to open main menu, then select Sonar
  - Noise Filter: Off or 1 (not needed for kayak w/o motor)
  - Digital Depth Source: Auto 
  - Water Type: Fresh
  - Verify CHIRP configuration (p. 41):
    - Main Menu > Setup > CHIRP Configuration 
    - 2D mode, DI or Imaging mode should be On, SI mode should be Off
  - Frequency settings (p. 45):
    - 2D CHIRP Display Frequency/Spectrum: 
      - Full: Use complete frequency range
      - Narrow: Increased bottom detail and target separation
      - Wide: Maximize coverage and show big fish arches
    - DI CHIRP Display Frequency:
      - 800 kHz: for shallow water (up to 125') and sharpest image
      - 455 kHz: for deep water (up to 400')
  - Filter Surface Clutter: Decrease if needed to reduce noise from algae or aeration
  - 2D SwitchFire: Clear Mode shows interpreted sonar signal and reduces noise, Max shows raw sonar data
  - Fish ID+: Turn on to show fish symbols
    - Fish ID Sensitivity: Decrease to show only larger fish
    - Fish ID Alarm: Turn on/off
  - Bottom View: Set to White Line to highlight strongest sonar return in white
- Set time and date: Press MENU twice to open main menu, then select Setup
- Set default waypoint icon to fish: Press MENU key twice, Nav tab, Waypoint Settings, Default Waypoint Icon

## Selecting Views
To choose between sonar, down imaging, chart, and combo views:
- Press and hold VIEW
  - Select Sonar to choose between sonar, down imaging, and sonar/down imaging combo views 
  - Select Chart to choose between chart and chart/sonar/down imaging combo views
 
## Adjusting Sonar
With sonar on screen:
- Use +/- keys to adjust overall sensitivity (or zoom when in zoom view)
  - Decrease sensitivity in murky water to reduce noise, increase in clear or deep water
- Press Check ("P") to switch between sonar frequencies
  - TODO: See what frequencies are available and check charts on p. 45
- Use cursor to freeze and review sonar history; distance and bearing to cursor position will be shown
- Press and hold VIEW and select Split View to split screen with each sonar frequency, to compare views
- Press and hold VIEW, select Zoom View, and use +/- and cursor to magnify areas of screen 
- Press Menu to open Sonar X-Press menu
  - Adjust overall sensitivity here as well
  - Also adjust sensitivity of individual frequencies
  - Adjust Contrast: 20 is default and uses full color range
  - Upper/Lower Range: Use to manually control range of water column shown and increase detail in that area. When lower range is set to Auto unit will follow the bottom depth.
  - Chart Speed: How fast sonar history moves across the view
- Sonar waypoints and navigation:
  - With cursor active, press MARK to create a waypoint at the cursor position
  - With cursor active, press GOTO twice to navigate to the point 
 
## Adjusting Down Imaging
With DI on screen:
- Use +/- keys to adjust sensitivity
  - Decrease sensitivity in murky water to reduce noise, increase in clear or deep water
- Press Check ("P") to switch between DI frequencies 
  - TODO: See what frequencies are available and check charts on p. 45
- Press Menu to open DI X-Press menu
  - Adjust sensitivity here as well
  - Select Enhance to adjust sensitivity (again), Contrast, and Sharpness of DI view
  - Upper/Lower Range: Use to manually control range of water column shown and increase detail in that area. When lower range is set to Auto unit will follow the bottom depth.
  - Chart Speed: How fast sonar history moves across the view
  - DI Colors: Change DI color palette
- Use cursor to freeze and review DI history; distance and bearing to cursor position will be shown
- Zoom in on a DI view:
  - Use cursor to freeze DI view and go to area, press +/- keys to zoom into area, press EXIT to return
- DI waypoints and navigation:
  - With cursor active, press MARK to create a waypoint at the cursor position
  - With cursor active, press GOTO twice to navigate to the point 
 
## Customizing Chart Views
- Press Power and select background to change chart background color
- Press Menu twice to open main menu and press Chart to access customization options like chart orientation, auto zoom, latitude/longitude lines, depth shading, and chart detail levels
- With a chart on screen, press Menu to open the Chart X-Press menu
  - Chart Declutter: Simplifies chart view
  - AutoChart: Adjust depth range, contour interval, map position, color palette, and shading
- Use cursor and +/- buttons to zoom and change perspective in chart views
 
## Navigation
- Press MARK to create a waypoint at the boat position
- Press MARK twice to create a waypoint at the cursor position
- With the cursor over a waypoint or position, press GOTO twice to navigate there. Repeat with additional waypoints to create a route, and save route from the Chart X-Press menu.
- To reset the route to the next waypoint from the current position (if you have gone off route), with a chart on screen, press GOTO and select Reset XTE
- Cancel navigation from the Chart X-Press menu
- To manage waypoints and routes, press MENU twice, Nav tab, Waypoints, Routes, and Tracks

## Kayak Installation

    - Battery disconnect

      - Black wire
    - Battery disconnect
  - Negative battery terminal
