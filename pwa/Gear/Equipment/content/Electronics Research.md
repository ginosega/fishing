## Chart Plotter / Fish Finder
- Garmin technologies:
  - ClearVu: Down-scanning sonar. High resolution but limited field of view.
  - SideVu: Side-scanning sonar. More area than ClearVu but less resolution.
  - Live Scope: Forward-facing sonar. Requires a compatible screen, transducer, and black box.
- Garmin naming conventions:
  - EchoMap: Family name, as opposed to GPSMap or Striker. E.g., **EchoMap** Ultra 2 106SV.
  - Ultra 2: Upgrade from discontinued Ultra. Supports larger (10"+) screens with improved GPS, mapping, and OS over UHD2. E.g., EchoMap **Ultra 2** 106SV.
  - UHD2: Upgrade from discontinued UHD.Ssupports screen sizes up to 9".
  - First 1-2 numbers: Screen size in inches (7, 9, 10, or 12). Go for 10" for a kayak. E.g., EchoMap Ultra 2 **10**6SV.
  - Second number: Pre-loaded maps: 2=worldwide base map, 3=US lakes, 4=coastal, 5=Canada lakes, 6=lake and coastal maps (reserved for 10"+ Ultra units). Can add more maps later. E.g., EchoMap Ultra 2 10**6**SV.
  - Letters:
    - SV: Both SideVu and ClearVu. E.g., EchoMap Ultra 2 106**SV**.
    - CV: ClearVu only, no SideVu. Don't buy.
- Live Scope:
  - "LVS" = Live Scope
  - LVS34 is Live Scope Plus, with improved resolution - get this.
  - LVS32 is older generation
  - Set gain to 70%
  - Show a bit of the bottom at the bottom of the screen
- Transducers:
  - ClearVu and SideVu use the same transducer
  - GT56UHD - higher resolution than GT54. Get transom mount (see below).
  - A separate transducer is required for Live Scope. Install on a retractable rotating transducer arm.
