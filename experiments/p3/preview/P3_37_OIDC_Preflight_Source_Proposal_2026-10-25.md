## 2. P3-36 transport compatibility review

- P3-36 fixed the **source-level** P3-35 transport gap: a versioned canonical envelope carries the original signed 8,192-byte inner command, GitHub OIDC JWT, ECDSA-signed owner approval and HMAC along the proposed public Access-to-private-service-binding boundary.
- Access service authentication and owner/run authentication must remain **separate trust proofs**. The ingress validates only the Cloudflare service-token identity and exact route; the private command receiver must verify the real GitHub-signed OIDC (plus actual App installation metadata), real owner ECDSA signature, and HMAC before a single D1 atomic accept/nonce/approval/snapshot/audit transaction. No proof flag transported from an untrusted client may substitute for signatures.
- Outer 24,576-byte canonical UTF-8 limit and inner 8,192-byte limit remain **provisional**, only demonstrated with local fixtures. The real issuer token length, on-wire Access assertions, JWKS fetch latency, Worker Free CPU limit and cloud service-binding behavior remain unproven. Remote networking and migrations require separate approvals. No media/upload support is inferred.
- An OIDC probe for `.github/workflows/fishing-p3-oidc-readonly.yml` cannot authorize a different publishing workflow `.github/workflows/p3-trusted-command.yml`. Each has its **own exact signed `workflow_ref` and `workflow_sha`**. Proving the former gives a scoped provider-format check only; the production or sandbox publishing trust policy must still undergo independent signed provenance and App checks.
- Remaining non-transport blockers include owner signing-key custody, actual GitHub App installation permissions, real Cloudflare Access JWT claims, atomic approval migration and service-binding-only receiver wiring. None is bypassed by this probe.

## 3. Proposed preflight, deliberately non-executable

New **public draft PR source** files:

- `src/p3-oidc-readonly-preflight.mjs`: a **pure injected-JWKS verifier**, verifying an actual RSA-signed GitHub-style OIDC JWT with pinned issuer `https://token.actions.githubusercontent.com`, exact GitHub sandbox and owner numeric IDs, `workflow_dispatch` on private `main`, `github-hosted` runner, exact audience `fishing-p3:trusted-runner:owner-accept`, immutable default subject, `workflow_ref=ginosega/fishing-p3-sandbox/.github/workflows/fishing-p3-oidc-readonly.yml@refs/heads/main`, expected SHA/actor/run/attempt, bounded clock window. Rejects rogue reusable workflows, wrong `kid`, algorithms, JWT-provided JWKS URLs and malformed/unauthorized scopes before any positive output. Returns fixed nonsecret proof fields only.
- `src/p3-oidc-readonly-cli.mjs`: **direct-execution-only** host probe, not invoked on import. Refuses until `GITHUB_ACTIONS=true`, literal `P3_OIDC_PREFLIGHT_ENABLED=true` and exact immutable sandbox/owner/manual `main` run environment all agree. Uses GitHub's short-lived `ACTIONS_ID_TOKEN_REQUEST_URL` + `ACTIONS_ID_TOKEN_REQUEST_TOKEN` variables only to request one OIDC JWT with the fixed audience, with a pinned HTTPS `pipelines.actions.githubusercontent.com` request host, redirect denial, 5-second timeout and bounded reply. Downloads only public `https://token.actions.githubusercontent.com/.well-known/jwks`, verifies the JWT signature and claims locally. Prints one fixed redacted PASS sentence or a fixed DENY sentence; no raw token, header, claims, key, Authorization bearer, signing `kid` or upstream errors. **No GitHub App private key/installation token/Cloudflare credentials, token exchange, D1 access, GitHub write, PR or publishing capability.** If the real runner endpoint differs from the pinned host, it fails closed; review the *actual trusted* runtime endpoint before considering any host adjustment.
- `design/fishing-p3-oidc-readonly.workflow.PROPOSED.yml`: *outside* all executable `.github/workflows` directories. The **future target** would be private `ginosega/fishing-p3-sandbox/.github/workflows/fishing-p3-oidc-readonly.yml`, but the file is NOT there. Manual `workflow_dispatch` only, exact repository/actor/ref gate, `ubuntu-24.04`, max 5 minutes, serialized, global `permissions: {}`, job `contents: read` and `id-token: write` only; pinned `actions/checkout`, `persist-credentials: false`. Pulls a public-source commit by **immutable full SHA**, verifying `git rev-parse HEAD` before requesting OIDC. The template has an intentionally **invalid all-zero 40-digit source commit pin in BOTH checkout and guard**, and it will fail if merely copied as-is. Prior to any installation, an owner-approved source review must replace both with the same actual immutable commit and confirm the inspected source blob. **Do not grant broader permissions, add workflows, PR events, or Cloudflare/GitHub secrets.**
